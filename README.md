# Nebula Games V1.1

Primeira evolução funcional da plataforma Nebula Games.

## O que esta versão entrega

- Home da plataforma com catálogo dos jogos criados até agora.
- Fortune Lynx com interface jogável pronta para servir de base.
- Saldo demo local.
- Aposta ajustável.
- Giro funcional.
- Auto x10.
- Modo turbo.
- WILD, SCATTER e símbolos criados integrados na interface.
- 3 SCATTER ativam 8 rodadas grátis com multiplicador aleatório (2x, 3x, 4x ou 5x).
- Histórico lateral e tabela rápida.

## Como usar

1. Extraia a pasta do ZIP.
2. Abra `index.html` no navegador.
3. Clique em **Abrir Fortune Lynx**.
